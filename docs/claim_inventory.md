## 1. Scope and source boundary

This inventory was prepared from `AGENTS.md` and every document under `papers/`.
The five PDFs under `papers/tex/` are rendered counterparts of the corresponding
TeX sources and are not counted as independent evidence. No `specs/` directory
exists. The papers repeatedly refer to an original `results/`, `certificates/`,
`claims.yml`, `predictions.yml`, `measures.yml`, `proofs/`, and repository
history. Those sources are absent here and are forbidden clean-room inputs; they
will not be sought.

The claims are separated into two provenance classes:

- `MANDATE`: a required test stated by `AGENTS.md`, but not presently backed by
  a QRN core paper in this repository.
- `PAPER`: a claim or preregistered test stated in one or more supplied papers.

This distinction is load-bearing. A successful test of a `MANDATE` claim must
not be described as replication of a missing paper.

## 2. Tolerance and inclusion vocabulary

Tolerance codes are determined without using the papers' reported result values.

- `EXACT`: integers, finite-field ranks, symbolic equalities, canonical sets, or
  equivalence classes must agree exactly.
- `ROUND`: floating-point comparison uses
  `atol + rtol*scale`, with the budget derived before the run from machine
  precision, condition estimates, and analytic truncation bounds. Default
  constants are not set until the derivation document exists.
- `BIG`: an independent 256-bit-or-higher `BigFloat` calculation must contain the
  `Float64` result within its forward-error budget.
- `CONV`: the registered convergence order and a stable extrapolated interval
  must both pass; a single close value is insufficient.
- `STAT`: a preregistered confidence interval or coverage test must pass.
- `POST`: the paper's quoted number is quarantined until implementation,
  validation, freeze, and fresh holdout are complete; it is used only for the
  final comparison.

Inclusion values are `Required`, `Conditional`, `Cross-check`, or `Excluded`.
`Conditional` means that more than one reasonable interpretation must be tested,
or that a missing specification prevents a unique replication target.
